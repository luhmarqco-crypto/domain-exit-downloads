# Domain Exit

**[Download Domain Exit for Windows](https://github.com/luhmarqco-crypto/domain-exit-downloads/releases/latest/download/DomainExit-Setup.exe)**

1. Open the downloaded `DomainExit-Setup.exe`.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**
   (the setup file isn't code-signed yet).
3. Follow the installer. No administrator password is needed.
4. Open Domain Exit and press **Install**. It downloads the game and keeps it up to date.
